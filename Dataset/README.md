# Dataset

I used a publicly available real estate transactions dataset covering property sales recorded between 2011 and 2022 across 50 towns in Connecticut, USA.

The file is 36MB which exceeds GitHub's 25MB upload limit, so it is hosted on Google Drive. No sign-in is required to view or download it.

**Download the dataset here:**
https://docs.google.com/spreadsheets/d/1LfL_3CsfFAOtCHTuknQh6azqvEiR_JW2/view?usp=sharing

**Original government source:**
https://data.ct.gov/Housing-and-Development/Real-Estate-Sales-2001-2023-GL/5mzw-sjtu

**File used in this project:** Real_Estate_Sales_2011-2022_GL_1.xlsx

**What the dataset contains:**
- 526,276 property sale records
- 11 years of data (2011 to 2021)
- Fields include: Town, Sale Amount, Assessed Value, Sales Ratio, Property Type, Residential Type, List Year
